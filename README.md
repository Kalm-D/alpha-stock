# Alpha Stock Web

Bản web của Alpha Stock v1.20 PRO, giữ giao diện và logic của bộ gốc.

## Sử dụng

Mở website, nhập CSV giá và sử dụng các bộ lọc có sẵn. Danh sách theo dõi và thiết lập được lưu trong trình duyệt hiện tại, chưa đồng bộ giữa thiết bị.

Chức năng cập nhật trực tuyến có sẵn phụ thuộc API VNDIRECT và quyền truy cập từ trình duyệt. Bản triển khai này chưa bổ sung dịch vụ Python chạy nền hoặc tự động cập nhật dữ liệu.

## Xuất bản bằng GitHub Pages

Trong Settings → Pages, chọn Deploy from a branch, nhánh main và thư mục / (root), rồi lưu.

Không đưa API key, file .env hoặc danh mục cá nhân lên kho công khai.
